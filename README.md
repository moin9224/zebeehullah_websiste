# Mufti Zabeehullah Leghari — Official Academic & Juristic Portal
**Bridging Classical Heritage with Contemporary Thought**

An advanced, full-fledged Next.js 14 web application designed and built according to the official blueprint for **Mufti Zabeehullah Leghari** (مفتی ذبیح اللہ لغاری) — CEO of Dar ul Ifta Daharki and Director at the Institute of Islamic Sciences (Daharki, Sindh, Pakistan).

---

     - **Rooted in Tradition (اصالت)**: Qur'an, Sunnah, Usul al-Fiqh, and classical heritage.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS with custom Islamic scholarly palette (Emerald, Warm Gold, Parchment)
- **Icons**: Lucide React
- **Typography**: Google Fonts (*Playfair Display*, *Amiri*, *Scheherazade New*, *Noto Nastaliq Urdu*, *Plus Jakarta Sans*)

## 🚀 Running the Project Locally

```bash

npm install

# 2. Start development server
npm run dev

# 3. Open in browser
http://localhost:3000
```

## ☁️ Deployment on Vercel

This repository is pre-configured for one-click deployment on [Vercel](https://vercel.com):

1. Go to [Vercel](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New..."** → **"Project"**.
3. Select your GitHub repository: `moin9224/zebeehullah_websiste`.
4. Vercel automatically detects Next.js using the included `vercel.json`.
5. Click **"Deploy"**. Your website will be live in ~1 minute with automatic SSL and global CDN!
